## Описание
Расширение системы управления данными с поддержкой файлового хранилища. Данные сохраняются на диск в формате JSON и загружаются при запуске программы.

## Функциональность
- Создание таблиц с произвольными полями
- CRUD операции с записями
- Фильтрация и сортировка
- Два режима: in-memory и файловый (JSON)
- Автоматическое сохранение/загрузка
- Консольный интерфейс на русском языке
