## Описание
Прототип базы данных, функционирующей в оперативной памяти (in-memory), с поддержкой CRUD-операций и фильтрации записей.

## Структура проекта
task2/
├── src/
│ └── db/
│ ├── backend/
│ │ ├── init.py
│ │ └── memory.py # логика работы с данными (классы Table и InMemoryDB)
│ ├── init.py
│ ├── main.py # точка входа в приложение
│ └── tui.py # консольный интерфейс
└── README.md

## Функциональность
- Создание произвольного количества таблиц с заданными полями
- Добавление записей с автогенерацией уникального ID
- Чтение всех записей таблицы
- Чтение записей с фильтрацией по одному или нескольким полям
- Обновление существующих записей по ID
- Удаление записей по ID
- Обработка ошибок (некорректный ввод, отсутствие таблиц/записей, дублирование имён)
- Консольный интерфейс на русском языке
