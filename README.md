## Функциональность

# Базовая функциональность
- Создание произвольного количества таблиц с заданными полями
- Добавление записей с автогенерацией уникального ID
- Чтение всех записей таблицы
- Чтение записей с фильтрацией по одному или нескольким полям
- Обновление существующих записей по ID
- Удаление записей по ID
- Сортировка записей по выбранному полю

# Дополнительные возможности
- **Три типа хранилищ:**
  - In-Memory (оперативная память) - данные теряются после завершения
  - JSON (файловое) - данные сохраняются в JSON файлах
  - CSV (файловое) - данные сохраняются в CSV файлах с метаданными
- **Индексация полей** для ускорения поиска
- **Автоматическое сохранение** при изменении данных (для файловой БД)
- **Автоматизированные тесты** (покрытие > 80%)

## Различия между реализациями

# In-Memory Database
- Хранение данных в оперативной памяти
- Высокая скорость работы
- Данные теряются после завершения программы
- Не требует сохранения на диск

# JSON Database
- Хранение данных в JSON файлах (data/*.json)
- Каждая таблица - отдельный JSON файл
- Сохраняет полную структуру таблицы (включая индексы)
- Автоматическая загрузка при старте

# CSV Database
- Хранение данных в CSV файлах
- Данные таблицы - CSV файл, метаданные - JSON файл
- Меньший размер файлов по сравнению с JSON
- Совместимость с табличными редакторами

## Запуск
python -m src.db - In-Memory (по умолчанию)
python -m src.db json - Файловая JSON
python -m src.db csv - Файловая CSV
